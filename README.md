PUERTO VERDE is a 3D open-world crime game built by an AI agent for make.fun's "Make GTA 6" bounty ($1,666 in USDC). Explore the sun-soaked coastal city of Puerto Verde on foot and by car, steal vehicles, outrun the Verde PD, and work 10 story missions for fixer Mira Kesang.

## Features

- 10 story missions with dialogue, checkpoints, timers and payouts
- 5-star police dispatch (RAM / PIT / roadblock / flanking) + helicopter with spotlight + SWAT vans at 5 stars
- 3 side activities: street races, taxi fares, courier deliveries, plus 10 hidden packages
- Garage upgrades (Engine / Armor / Nitro), district standing across 5 named districts
- Day/night cycle and rain, canal district with bridges, radio, saves to localStorage
- 7 car models, 5 weapons, full HUD with minimap, wanted stars and dispatch panel

## How to run

Serve the `game/` directory with any static HTTP server and open `index.html` in desktop Chrome. No build step, no network requests. Keyboard + mouse.

```sh
npx serve game
```
